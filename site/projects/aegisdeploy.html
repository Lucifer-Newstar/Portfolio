.github/workflows/ci.yml

The CI pipeline

Every push and pull request to main runs six CI jobs, and all of them must pass before a merge: YAML and compose validation, Kubernetes manifests (kubeconform + kustomize), a docs link check, the backend (ruff, mypy, pytest), Docker image builds and the frontend build. This animation walks through them. It's an illustration, not live build status.

7 services on Kubernetes

Each service has its own Deployment and Service manifest, assembled by one Kustomize base and validated with kubeconform in CI. Three make up the platform; four make up AegisShop, a demo shop for the platform to watch.
