What it does

Ascend turns fitness into an RPG: training and diet choices drive character progression, computed by deterministic engines so results are explainable and reproducible. Everything runs offline on Windows.

Where it stands

Both suites are green locally (612 + 1,228 tests). GitHub CI is being repaired: a missing system package in the ML workflow, a test that assumes a path depth, and a Windows file-lock in a fixture. Small, known breaks with fixes in flight.
