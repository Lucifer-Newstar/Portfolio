The seven modules

  • Linux, Git and shell scripting fundamentals
  • Docker: images, Compose stacks and smoke tests on a real Docker host
  • CI/CD with GitHub Actions
  • AWS infrastructure: EC2, RDS, S3 and CloudFormation templates, checked with cfn-lint
  • Monitoring with CloudWatch logs and metrics
  • A capstone that ties them together

Bugs found by running it for real

  • A healthcheck that failed under cron (PATH) and probed the wrong routes
  • All container logs landing in one literal log stream
  • An OIDC trust policy that was referenced but never committed, then broke on GitHub's new token format

Each was diagnosed from real evidence (CloudTrail, logs) and fixed; every test suite in the repo was executed, none skipped.
