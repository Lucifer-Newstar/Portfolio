What I built

  • Static hosting on S3 behind CloudFront
  • APIs on API Gateway + Lambda
  • DynamoDB for data, Cognito for auth, SES for email
  • Automated deployment with a GitHub Actions workflow

Why serverless

No servers to patch or keep running: each piece is a managed AWS service, and the whole thing deploys from a git push.
